# 01 · 确认机型和系统版本

刷机前必须先搞清楚两件事：**你是哪台机器**、**现在是什么版本**。
这两个信息决定了你要下哪个文件 —— 下错了就是砖。

---

## 一、查型号

### 方法 1：设置里看

`设置` → `关于` → `硬件` / `型号`

会看到类似 `STL100-3`、`SQN100-5`、`SQW100-4` 这样的编号。

### 方法 2：拨号盘指令（最快）

打开拨号盘，输入：

```
myver
```

注意是 `myver` 后面**跟一个空格**，然后它会自动补全成 `myver ` 并显示版本。
有些版本不显示型号，那就用方法 1。

### 方法 3：拆后盖看电池仓

电池仓里的标签上印着型号，最准，但要拆机。

---

## 二、查系统版本

`设置` → `关于` → `软件版本`

BB10 有两个版本号，别搞混：

| 名称 | 例子 | 说明 |
|---|---|---|
| 软件版本（Software Release） | `10.3.3.2137` | 面向用户的版本，宣传口径 |
| OS 版本（OS Version） | `10.3.3.3216` | 真正的系统 build，**刷机和 Root 看这个** |

社区说的「3216」指的是 **OS 版本 10.3.3.3216**（对应软件版本 10.3.3.2137）。

```bash
# 也可以这样查（需要先装好环境，见 03）
./bb10-root/bb10mt info
```

## 三、型号 → 固件对应表

BB10 有几组机型的固件是**通用**的，这大大减少了找文件的难度。

| 你的机型 | 型号编号 | 用哪个包 |
|---|---|---|
| Z30（全部） | STA100-1 ~ -6 | `Z30_10.3.03.3216_STA100-1-2-3-4-5-6` |
| Classic / Q20 | SQC100-1 ~ -5 | 同上（与 Z30 通用） |
| Leap | STR100-1 / -2 | 同上（与 Z30 通用） |
| Q10（全部） | SQN100-1 ~ -5 | `Q10_10.3.03.3216_SQN100-1-2-3-4-5` |
| Q5（全部） | SQR100-1 ~ -3 | 同上（与 Q10 通用） |
| Porsche P9983 | P9983 | 同上（与 Q10 通用） |
| Z10 | STL100-2 / -3 | `Z10_10.3.03.3216_STL100-2-3` |
| Porsche P9982 | P9982 | 同上（与 Z10-2/3 通用） |
| **Z10** | **STL100-1** | `Z10_10.3.03.3216_STL100-1` ⚠️ **单独一份，不能混用** |
| **Z3** | STJ100-1 / -2 | `Z3_10.3.03.3216_STJ100-1-2` ⚠️ **单独一份** |
| **Passport** | SQW100-1/2/3/4 | `Passport_10.3.03.3216_SQW100-1-2-3-4` ⚠️ **单独一份** |

### 三个大坑

1. **Z10 STL100-1** 用的是德州仪器 OMAP 芯片，其他 Z10 是高通。固件完全不通用，刷错直接砖。
2. **Passport** 有 SQW100-1/2/3/4 四个后缀，对应不同地区/运营商，但**固件是同一份**，文件名会包含全部后缀。
3. **Z3** 只有 STJ100，独一份。

> 记不住也没关系：**文件名里的型号段必须完整包含你手机上的编号**。
> 比如你是 STA100-3，就找文件名里有 `STA100-1-2-3-4-5-6` 的包 —— 包含了 3，没问题。
> 如果文件名里根本没有你的编号，别刷。

## 四、BB10 插到 Mac 上是什么样

这点和 Android 完全不同，第一次接触的人都会被搞懵。

**BB10 插上 Mac 不会出现 U 盘。** 它枚举成一张**虚拟网卡**：

```
系统信息 → 硬件 → USB
  Research In Motion ... 
```

网络设置里会多出一个接口，设备端固定在 `169.254.0.1`，你的 Mac 拿到 `169.254.0.2`。
所有通信（装应用、备份、调试）都走这条 USB 网线，跑的是 HTTP/HTTPS。

这意味着：

- 用 `adb` 是连不上的（BB10 不是 Android）
- 装 BAR 要用 Sachesi / DBBT，它们走的就是这条网线
- **刷机不需要这条网线** —— 刷机走的是更底层的 bootrom，设备会重新枚举成一个 RIM 的 USB 设备

### 不要开「USB 大容量存储」

`设置` → `存储和访问` → 关掉「USB 大容量存储」。

开着的话设备会伪装成 U 盘，刷机工具就找不到它了。默认也是关的，但有些人手动开过。
