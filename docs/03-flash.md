# 03 · 在 Mac 上刷机

这一节做一件事：**把手机刷成官方 10.3.3.3216**。
不管你是想修砖、想降级、还是想为 Root 做准备，都要先走到这一步。

---

## 原理（30 秒看懂，不看也能刷）

Windows 上的老办法是双击 `Passport_xxx.exe`，它自己找设备、自己刷。

那个 `.exe` 拆开是两块：

```
┌─────────────────────────────┐
│  cap.exe（刷机引擎，386 程序）│
├─────────────────────────────┤
│  固件镜像 0.signed  (~3 GB)  │  ← 系统分区
│  固件镜像 1.signed  (~38 MB) │  ← radio / 基带
└─────────────────────────────┘
```

Mac 上我们不跑 `cap.exe`，而是：

1. 用 `bb10mt split` 把后面的镜像**拆出来**
2. 用 `bb10mt flash` 通过 USB 直接写进设备的 bootrom

`bb10mt flash` 干的事和 `cap.exe` 一模一样，都是往 RAM loader 发同一套命令。
**唯一的区别是它跑在 Mac 上。**

---

## 准备工作清单

- [ ] 手机电量 **50% 以上**（刷到一半没电 = 砖）
- [ ] 一根**能传数据**的 USB-A/C 线（劣质充电线是失败第一大原因）
- [ ] 直插 Mac 的 USB 口，**不要用 hub、不要用延长线**
- [ ] 拔掉 SIM 卡和 SD 卡
- [ ] 关掉「USB 大容量存储」（`设置 → 存储和访问`）
- [ ] 记住锁屏密码（刷机中途可能会问）
- [ ] 数据已备份（刷完全清，不可恢复）

备份方式：BB10 官方服务已死，`BlackBerry Link` 也用不了。
实际可行的是：照片/文档拷到 SD 卡或电脑，联系人导出 vCard，聊天记录……基本没救。

---

## 第 1 步：拆包

```bash
cd bb10-macos-guide/bb10-root

./bb10mt split -i autoloader/Passport_10.3.03.3216_SQW100-1-2-3-4.exe -o split
```

成功的话 `split/` 里会出现：

```
split/
├── Passport_....0.signed     ← 大的，系统分区（约 3 GB）
├── Passport_....1.signed     ← 小的，radio（约 38 MB）
└── （可能还有一些 .sig / .mbr / .ufs，忽略）
```

> 只需要刷 `.signed` 文件。`.sig` 是签名、`.mbr` 是分区表、`.ufs` 是底层镜像，`flash` 自己会处理。

---

---

> ⚠️ **本篇讲的是刷「官方固件」。如果你要刷的是 root 包，别照这里做。**
> root 包要刷的是 `batch` 产出的 `0.unsigned`（不是 `.signed`，`.signed` 是没补丁的原件），
> 而且 OS 和 radio 必须写在**同一条命令**里一次刷完，否则设备刷完不启动。
> 详见 [08 · Classic/Q20 实机记录](08-classic-q20.md)。

## 第 2 步：让手机进 bootrom

这一步的顺序很关键，很多人卡在这。

```bash
./bb10mt flash -i split/Passport_....0.signed
```

执行后终端会**停在那里等设备**（可能出现 `Waiting for device` / `Connecting to bootrom`）。

这时候：

1. 手机**关机**（长按电源键 → 关机）
2. 插上 USB 线
3. 如果 30 秒内没反应，**按住电源键开机**，保持插着线

设备一旦被识别，屏幕会亮、指示灯变**绿色**，然后开始刷。

> **红灯常亮** = 正在写 flash，正常现象，别慌别拔线。
> **红灯闪 / 屏幕黑着** = 也在正常刷，BB10 刷机时屏幕基本没反馈，看终端进度。

---

## 第 3 步：刷 radio

第一个包刷完，终端会提示完成，手机可能自己重启。

```bash
./bb10mt flash -i split/Passport_....1.signed
```

如果手机已经重启进系统了，**重新执行上面的命令，然后关机再插线**，走一遍第 2 步的流程。

两个包都刷完，手机会自动重启，进到初始化界面。

---

## 第 4 步：跳过初始化（这一步最容易卡）

到这里你会发现一个残酷的现实：**BB10 的初始化向导要连 BlackBerry 服务器，而服务器 2022 年就关了。**

卡在「连接 WiFi」或者「登录 BBID」页面出不去，是 2026 年刷 BB10 的必经之路。

### 破解办法：用屏幕阅读器跳过

原理是：开启「屏幕阅读器」后，系统会多出语音引导和「跳过」按钮，而这些按钮的判定逻辑不依赖服务器。

1. 正常开始初始化，走到 **「连接 WiFi」** 页面，随便连一个网络
2. 如果能把初始化向导划掉关掉 —— 关掉，等通知栏弹出「完成设置」，再从通知点进去
3. 走到 **「连接移动网络」** 页面时，**快速连按三次电源键**
4. 屏幕阅读器会启动（**可能要等 10 分钟才出声**，别急，不行就再按三次）
5. 用**两根手指双击屏幕**激活屏幕阅读器
6. 在「连接移动网络」页点 **Skip**（跳过）
7. 下一页又是「连接 WiFi」，**等着**，听到屏幕阅读器念 BBID 相关的提示
8. 听到 "Skip" 的瞬间，**在页面标题正下方双击**（两根手指）
9. 会弹出「是否跳过 BBID」→ 点 **Skip**
10. 继续往下走，到「软件更新」页 → 忽略 → 「设置完成」

> 语音不响？把音量调大，或者在「辅助功能」里手动开屏幕阅读器再回来。
> 这个流程可能要重复两三遍才成功，属于正常现象。

### 更省事的办法

如果你只是为了 **Root** 而刷机，那 `04 · 注入 Root` 里生成的 root 包已经内置了跳过初始化的配置
（`patch.txt` 里那段 `tutorials_*_done` 就是干这个的）。
**直接刷 root 包，跳过这一步。**

---

## 第 5 步：验证

```bash
./bb10mt info
```

能看到设备型号、OS 版本、PIN 就说明连接正常。
手机端 `设置 → 关于 → 软件版本` 应该是 `10.3.3.2137`（OS `10.3.3.3216`）。

---

## 想刷回原厂？

任何时候想回到干净状态：

```bash
./bb10mt split -i autoloader/官方包.exe -o split-official
./bb10mt flash -i split-official/xxx.0.signed
./bb10mt flash -i split-official/xxx.1.signed
```

也就是说 **官方包本身就是最好的救砖工具**。
只要你的包没下错、线没问题，刷坏了基本都能刷回来。

## 卡住了？

- `flash` 一直等设备 → 见 [06 · 排错](06-troubleshooting.md#flash-一直等不到设备)
- 报 `Couldn't load dynamic library libusb` → 你跳过了 `setup.sh`，回去跑一遍
- 报错说不认识这个文件格式 → 用 `split` 拆出来的 `.signed` 再刷，别直接喂 `.exe`
